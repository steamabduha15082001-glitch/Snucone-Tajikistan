# Snucone Tajikistan — Dental Market

React + Vite landing page for the official Snucone distributor in Tajikistan.

## Start

```sh
npm install
npm run dev
```

## Contact form

Create a Formspree form and set `VITE_FORMSPREE_ENDPOINT` to its endpoint (see `.env.example`). The form reports success only after Formspree accepts the request. The phone number and email displayed in the design are placeholders and should be replaced with Dental Market's confirmed contact details before launch.
